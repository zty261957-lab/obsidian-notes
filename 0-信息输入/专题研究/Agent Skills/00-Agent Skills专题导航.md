> [!abstract] 专题目标

## 信息处理规则

1. 外部作者的原始观点、视频和文章进入本专题。
2. 可复用且经过验证的结论，沉淀到 `8-方法论/Skill方法论`。
3. 用于PPT、文章或课程的表达，进入 `6-内容生产/课程与培训/Skill编写培训`。
4. 播放量、点赞量和粉丝量均保留核验日期，不作为永久事实。
5. 小红书点赞、公众号阅读量和视频播放量不混用、不直接比较。

## 当前研究问题

- 高质量 Skill 与普通提示词的分界是什么？
- 如何把 Skill 从“能写”推进到“能运行、能验证、能维护”？
- 初学者教学应先讲概念，还是先让学员完成第一个可运行案例？
- Skill、MCP、Workflow、SubAgent 分别解决什么问题？
- 企业场景下需要补充哪些权限、安全、审计和人工确认机制？
