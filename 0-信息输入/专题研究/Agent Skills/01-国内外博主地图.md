## 微信公众号专项研究

微信公众号文章不公开稳定阅读量，因此不能按B站和YouTube的播放量口径直接筛选。公众号部分采用“主题相关度、内容完整性、案例证据、工程深度、更新持续性”五项进行内容筛选，流量数据单独标记为待核验。

首批建议重点关注：

- **雅典娜社区**：工业级Skill方法、权限边界、验证、评分和迭代。
- **AI技术立文**：成功标准、测试Prompt集、运行结果捕获和评测。
- **银河智学技术**：规范、运行时、上下文管理与治理。
- **数字安全推进计划**：安全边界、双用风险、授权和留痕。
- **NLP奇幻之旅**：概念入门和小型实践，适合教学参考。
- **AIML实验室**：从零创建、安装和寻找社区Skill。
- **FunTester**：探索性Skill、边界条件和样例适配。
- **海燕技术栈**：从编写到使用的开发路径及垂直案例。
- **脑子进煎鱼了**：面向开发者的概念解释与使用判断。

## 六位核心研究对象

1. **马克的技术工作坊**：底层逻辑和全景认知。
2. **技术爬爬虾**：Skill、MCP、Tool协作关系和源码实操。
3. **秋芝2046**：小白教学和首个成功体验。
4. **Kevin Stratvert**：专业教程节奏和屏幕演示结构。
5. **AI Foundations**：开发、测试、迭代和分享的生命周期。
6. **小博的AI产品笔记**：稳定可用、业务复用和检查清单。

## 内容流派

| 流派 | 代表博主 | 可迁移精华 |
|---|---|---|
| 底层逻辑型 | 马克的技术工作坊、技术爬爬虾 | 说明Skill为什么存在及其在AI能力体系中的位置 |
| 小白带练型 | 秋芝2046、Kevin Stratvert | 边讲边做，让学习者尽快获得第一个成果 |
| 工程体系型 | AI Foundations、Ali H Salem、程序员鱼皮 | 补齐需求、结构、开发、测试、发布和维护 |
| 业务结果型 | 技术胖、WorkFisher | 以工作成果为终点，而不是以文件编写为终点 |
| 卡片传播型 | 小博的AI产品笔记、空格键盘、PM刘搞定 | 用对比表、模板、检查清单和避坑卡片降低理解成本 |
