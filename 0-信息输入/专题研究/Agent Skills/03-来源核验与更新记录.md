# 来源核验与更新记录

## 统一口径

- B站、YouTube：记录视频公开播放量和核验日期。
- 小红书：记录公开点赞或收藏，禁止写成播放量。
- 公众号：只有在公开页面可核验时才记录阅读量。
- 同一作者跨平台重复发布时，分别记录，不合并成“全网播放量”。
- 无法重新核验的数据使用“前次检索约”，不写成精确当前值。
