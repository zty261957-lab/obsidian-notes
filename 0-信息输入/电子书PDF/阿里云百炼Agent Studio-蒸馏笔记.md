# §3 ⭐ 四大能力块

## 3.1 开发：三种范式（覆盖不同人）

| 范式 | 适合谁 | 特点 |
|------|-------|------|
| **Flow Agent** | **不懂代码的业务人员** | **拖拉拽可视化界面**、在线开发调试免运维、**0 代码端到端开发** |
| **ADK Build** | 研发 | 代码化集成开发、API 友好多协议兼容、**本地开发云端部署**、CI/CD 版本与环境管理 |
| **Vibe Coding** | AI 原生开发者 | **全能力 CLI 支持**、官方 Skill 开发实践、**兼容主流 Coding Agent**、一站式开发部署调用 |

## 3.2 ⭐⭐ 运行层（**工作台设计的直接参照**）

**Managed Agent** —— 托管式智能体运行时 · **零基建**
> **"仅需负责定义 Agent 业务逻辑 —— Agent = 组合配置（版本化）"**

**⭐ 五个核心抽象（这套抽象设计非常值得抄）**：

| 抽象 | 是什么 | 关键特性 |
|------|-------|---------|
| **Session 会话** | **一次运行实例（运行时中枢）** | **服务端持有状态**，**可中断 / 续跑 / 审批** ⭐ |
| **Event 事件流** | 会话内全部交互记录 | **服务端持久化 + SSE 实时订阅** ⭐ |
| **Environment 环境** | 云端容器沙箱 | 预装依赖、**可整体持久化** |
| **Agent 智能体** | 可复用能力定义 | **跨会话复用，每次保存自动生成版本** ⭐ |
| **Vault 密钥库** | 凭据集中托管 | — |

**另外两个组件**：
- **Sandbox**：全框架 Agent 托管服务，**毫秒级启停**、动态沙箱调度、安全隔离
- **AutoModel**：基于 **Agent Config + 用户 Query 智能路由**执行所需的模型，**隐式+显式缓存**支持

**⭐⭐ 划重点**：
> **「Session 可中断/续跑/审批」+「Event 服务端持久化」+「Agent 版本化」** ——
> **这三条正好解决"Agent 跑一半断了怎么办""怎么审计""怎么回滚"三个真问题** ✅
> **→ 你做工作台时，这套抽象可以直接参考** ⭐

## 3.3 ⭐⭐ 上下文层（**知识库/智能问答设计的直接参照**）

> **"文档、表格、图片、音视频统一入库，一次构建，全渠道调用。"**
> 由 **RAG / Memory / Parser X** 三者管理 Agent 上下文。

### RAG（Agentic RAG）

| 能力 | 说明 |
|------|------|
| **全模态知识解析** | 文档、表格、图片、音视频统一接入；复杂结构精准解析 |
| **Agentic Search 智能检索** | ⭐ **"像专家一样反复搜、多推理、汇总作答，复杂问题一步到位"** —— **不是单次检索，是迭代式** |
| **数据源动态更新** | ⭐ **连接器直连数据源，知识源头实时更新，不进"死库"** |
| **企业级知识治理** | 空间与权限分级管理、**答案全文引用、结论可溯源** ⭐ |

**解析准确率（厂商自述）**：文字 **>98%** · 版面 >90% · 公式 >95% · 表结构 >90%
**检索性能**：**150ms 毫秒级**、**MTEB 多语言检索第一**

### ⭐ Memory（超长上下文动态记忆）—— **三类记忆（这个分类很实用）**

| 类型 | 记什么 | 例子 |
|------|-------|------|
| **事实记忆** | 记住**发生过的关键事实与事件** | "我上周考试拿了年级第一" |
| **用户画像** | 记住**你是谁·稳定属性与偏好** | "考虑到你有高血糖，我选了低糖的杂粮饭" |
| **技能记忆** | ⭐ **记住"怎么做"·可复用的流程和经验** | "按你一贯的处理流程：我先去检索公司章程，再逐条比对合同条款" |

**⭐⭐ 划重点**：
> **「技能记忆」= 记住"怎么做"** ——
> **这正好对应你的 Skill 沉淀思路**：
> **Skill 是"写下来的方法"，技能记忆是"记下来的方法"** ✅
> **→ 智能问答机器人如果要"记住用户习惯"，这三类记忆就是现成的分类框架** ⭐

### Parser X
面向 Agent 的智能化解析服务：文件、文档、音视图文**多模态内容的解析与抽取**，多协议兼容调用。

## 3.4 ⭐⭐ 进化：Agent 数据飞轮（**评测体系设计的直接参照**）

> **"通过全链路 Trace 完整还原智能体的运行现场，用可复用评测集量化每一次输出的真实效果，
> 再基于反馈与实验结果智能优化 Prompt —— 精准定位问题、验证改进。"**

**四环飞轮**：
```
① 观测 → 看见真实运行
   全链路 Trace ｜ 调用/Token/模型/工具 监控 ｜ 限流统计 & 告警管理

② 评测 → 量化真实效果
   理想输出 + 轨迹 + 多模态 ｜ LLM + Code 评估 ｜ 自动打分 + 人工标注

③ 优化 → 问题优化解决
   多版本对比优化 ｜ 调试 + 反馈优化 ｜ 评测集 + 评测任务优化

④ 发布 → 改动可控生效
   调试验证回归 ｜ 版本修改对比 ｜ 人工确认发布
```

**飞轮的产物（可以复用的"进化资产"）**：
**观测 Trace → Bad Case → 评测集 → 评测结论 → 优化报告 → 版本调试 → 发布上线 → 观测 Trace…**

**⭐⭐ 划重点**：
> **「用可复用评测集量化每一次输出的真实效果，告别凭感觉发布」** ——
> **这正是你在做的"评测集设计"要做的事** ✅
> **而且它给了完整的闭环：Trace（过程）→ 评测集（标准）→ Bad Case（样本）→ 优化 → 版本发布** ⭐

| 层 | 内容 | 数量/说明 |
|---|------|----------|
| **MCP** | **企业 MCP + 生态 MCP 双轮驱动**，PVL 加密直连 VPC 打通企业 | **100+** MCP 生态供给 |
| **Skill** | **可信可控 Skill Hub** —— **内容型 + 脚本型支持**，支持**动态版本更新** | **1,000+** Skill 供给 |

**一个密钥的商业设计（值得借鉴）**：
| 卖点 | 说明 |
|------|------|
| **一个密钥** | **统一鉴权，无需向每个服务商单独申请账号** |
| **一份账单** | 统一计费，生态服务合并结算 |
| **一键接入** | 标准化 SDK，接入即用 |
| **无感开通** | **免注册免开通，开通即可调用** |

**⭐ 注意 Skill 的分类**：**内容型 + 脚本型** ——
**和你学到的「指令 / 代码 / 资源」三类相似** ✅

# §5 Agent 安全：六大核心能力

> **安全内生，开箱即防** —— 安全能力**原生内建**、与平台深度融合；
> **Agent 上线即默认受保护、零代码改动**；基础守护默认开启，高阶防护按需叠加。
> 闭环逻辑：**「量 → 挡 → 记」**

| # | 能力 | 做什么 |
|---|------|-------|
| **①** | **资产安全** | 盘点 Agent 及其关联资源，掌握资产分布与风险状态 |
| **②** | **内容安全** | 识别**提示词攻击、越狱与敏感内容**风险 |
| **③** | **工具安全** | 监测**工具调用与高风险操作**，降低越权调用风险 |
| **④** | **知识与记忆安全** | 保护 RAG 知识与 Agent 记忆，**防范违规及敏感信息风险** |
| **⑤** | **身份安全** | **统一人、设备与 Agent 身份**，支持认证与权限管控 |
| **⑥** | **审计追踪** | 记录 Agent 运行行为与安全事件，支持审计与行为溯源 |

**企业级可信基础**：密钥 Vault 集中托管可回收 ｜ 全链路加密传输 ｜ 统一身份与权限分级管理 ｜ 会话事件流实时订阅 ｜ **Eval & Trace 全链路监测** ｜ 多租户资源与访问隔离 ｜ **客户数据不用于模型训练**
**合规**：SOC 2、ISO/IEC 42001、**等保 2.0**、中国信通院大模型安全认证
**兼容**：API / SDK / CLI / MCP / Skill ｜ 主流 IDE 与 Agent 插件 ｜ **兼容 Dify / Coze**

# §6 其他值得记的

## 6.1 商业套件（Agent 怎么"卖"）
**Agent Store** —— **"让 Agent 从「能跑」到「能卖」"**
- **服务商代理体系 · 统一分账 · ISV 收益**
- **AI Payment**：订阅 / 付款 / 账单，**生产级商业闭环**
- 上架流程：产品沟通 → 场景共创 → 商务流程 → 协议签署 → 上架运营 → 售卖 → 技术服务支持
- 五种形态：**MCP**（工具连接）/ **Skill**（技能沉淀）/ **App**（垂类场景）/ **Agent**（**A2A 协议**、端到端交付）

## 6.2 硬件（Agent 走入物理世界）
**Agent Studio for Hardware**：穿戴 / 玩具 / 汽车 / 手机 / IoT / 具身智能
- 全双工实时交互（**语音端到端延迟 <1 秒**）
- 一套 SDK 覆盖 **Android/iOS/Linux/RTOS，30+ 硬件平台**

## 6.3 上手四步
```
① 开通阿里云百炼（一个 API Key 全能力通用）
② 选择开发范式（Flow Agent 或 Managed Agent）
③ 装配核心能力（知识库 / 记忆库 / One Key MCP / Skill，按需组合）
④ 体验与发布（Playground 在线验证，一键发布）
```

# §7 ⭐⭐ 对我们最有用（**对照你项目的四块**）
