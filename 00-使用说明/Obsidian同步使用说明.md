# 📘 Obsidian 同步使用说明

> 这篇笔记是 Hermes 推送的**同步验证**——如果你能在 Obsidian 里看到它，说明链路已经打通 ✅

---

## 🔄 同步机制

```
① 你把文章链接发给 Hermes（飞书）
        ↓
② Hermes 抓取正文 → 整理成规范笔记
        ↓
③ 推送到 GitHub 仓库（zty261957-lab/obsidian-notes）
        ↓
④ 你的 Obsidian 自动拉取（需开启自动拉取）
        ↓
⑤ 笔记出现在你的库里 ✨
```

---

## ⚙️ 开启自动拉取（一次性设置）

1. Obsidian → **设置** → 找到左侧的 **Git**（第三方插件设置）
2. 找到 **Auto pull interval (minutes)** → 改成 `10`
3. 找到 **Auto pull on boot** → 打开
4. 关闭设置

**设置完就不用管了**——每 10 分钟自动同步一次。

---

## 🖐️ 手动同步（想立刻看到更新时）

- **按 `Cmd + P`** → 输入 `Git: Pull` → 回车
- 或点左下角状态栏的 Git 图标 → 选 **Pull**

---

## 📥 以后怎么收录文章

**什么都不用做** —— 只要在飞书里把文章链接发给 Hermes 就行：

```
https://mp.weixin.qq.com/s/xxxxx
```

Hermes 会自动完成：抓取 → **提炼总结**（核心观点 + 关键数据 + 可迁移点 + 标签）→ 推送 → 你 Obsidian 自动出现。

> 📌 **笔记形态 = 提炼版**：只保留要点总结，**不放原文全文**；需要深入阅读时点笔记里的「原文」链接。
