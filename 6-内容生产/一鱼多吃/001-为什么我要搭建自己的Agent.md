# 为什么我要搭建自己的 Agent

## 原始素材

> 以下保留本轮原始表达，不将目标或设想补写成已经实现的结果。

1. 因为我想解脱我的双手。我觉得人是不应该一直坐在电脑面前办公的，更重要的是想法、判断及最终决策。
2. 目前写公众号成为我最重复、最烦的任务，因为我平时工作任务比较繁重。之前是一个字一个字码，现在在学习搭 Agent 去写，后面希望能够解放生产力。
3. 希望 Agent 能快速帮助我完成选题研究，用通俗易懂的话去写，让读者从文章中得到启发，并且跟着文章中的方法完成一件原本较难完成的事。
4. 文章的最终选题、脉络结构和主题思想必须由我判断。
5. 我希望以后去探索更多有意思的事：发现什么能干、为什么这么干、有没有更好的做事方法；再把这些探索记录和方法分享出来，让更多普通人能够跟着尝试。

## 已确认的观点

- 搭建 Agent 的目的不是让 AI 替代思考，而是把重复执行交给 AI，把人的时间留给想法、判断和最终决策。
- 公众号写作是当前希望优先改善的重复任务。
- 内容应该使用通俗易懂的表达，并给读者可以跟着实践的方法。
- 探索过程、失败、判断和更好的做事方法都值得被记录和分享。

## Agent 可以承担

- 根据目标和素材提供候选选题及选择依据。
- 整理原始素材，提取观点、事实和待核实信息。
- 根据已确认的结构生成草稿。
- 将专业概念改写成通俗易懂的表达。
- 根据人工反馈修改草稿，并记录修改原因。

## 必须由人决定

- 最终选题。
- 文章脉络与结构。
- 主题思想。
- 哪些观点代表本人立场。
- 哪些内容可以公开。
- 发布前终审与最终决策。

## 待确定

- 第一篇内容的最终选题。
- 文章结构与核心主题。
- 首轮需要生成哪些平台版本。
- 如何验证读者是否能够照着文章完成一件事。

## 长期目标（待验证）

- 通过 Agent 减少重复内容生产工作，把时间用于探索、实践和判断。
- 把探索过程整理成普通人可以理解、尝试和复现的方法。
- 逐步验证内容是否真正帮助读者完成原本难以独立完成的事情。
