# 待发布

这里存放**已经写好、但尚未发布**的内容（草稿 / 排期中的稿子）。

## 使用方式

- **新写的稿子**先放这里（未发布的都在这儿）
- **发布后**：移出本文件夹（或标注发布日期），或转入 `内容现状与方向` 的数据记录
- **命名建议**：`<平台>-<主题>-<日期>.md`（如 `小红书-AI提效-20260920.md`）

## 与相邻文件的关系

| 位置 | 作用 |
|------|------|
| **`待发布/`（本处）** | 成品稿，等发布 |
| **`内容现状与方向.md`** | 平台、当前效果、优先产出方向（策略层） |
| **`../0-信息输入/`** | 素材、灵感、客户原话（原料层） |
