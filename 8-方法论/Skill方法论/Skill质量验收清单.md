# Skill质量验收清单

## A. 任务与边界

- [ ] 一句话能说清要解决的任务
- [ ] 明确目标用户和使用场景
- [ ] 定义必需输入与可选输入
- [ ] 定义输出格式和保存位置
- [ ] 写明不负责的任务
- [ ] 写明必须停止或人工确认的情况

## B. 触发质量

- [ ] 正常表达能够触发
- [ ] 同义表达能够触发
- [ ] 相似但不属于本Skill的任务不会误触发
- [ ] 描述中没有“处理所有”“自动完成一切”等过宽表述

## C. 流程可执行性

- [ ] 步骤顺序明确
- [ ] 每一步有清晰动作和产物
- [ ] 工具、脚本和文件路径真实存在
- [ ] 关键业务规则可追溯
- [ ] 输入不足时知道问什么
- [ ] 工具失败时有安全退出或替代路径

## D. 输出与验收

- [ ] 输出符合模板和格式要求
- [ ] 关键字段完整
- [ ] 事实、数字和引用可核验
- [ ] 结果解决原始任务，而不只是“生成了文件”
- [ ] 有真实业务样例作为验收证据

## E. 安全与治理

- [ ] 不在Skill中保存口令、令牌和个人敏感信息
- [ ] 删除、覆盖、外发、发布等动作有确认点
- [ ] 权限范围遵循最小必要原则
- [ ] 明确哪些判断由人承担责任
- [ ] 失败不会造成难以恢复的数据损失

## F. 维护性

- [ ] 记录Owner、版本和更新时间
- [ ] 主文件不过度膨胀，细节按需拆分
- [ ] 包含正例、反例和边界样例
- [ ] 保存测试记录和已知问题
- [ ] 外部依赖变化后有复测方式
