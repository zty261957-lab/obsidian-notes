> [📅 打开或新建今日详情](obsidian://daily?vault=978f42a8977f6ffc) · [[9-首页/首页|知识库首页]] · [[0-信息输入/README|信息输入]] · [[6-内容生产/待发布/README|待发布内容]]

> 每天先打开“今日详情”，写下 1—3 件最重要的事；工作台会自动汇总任务和最近笔记。

## 今日任务总览

在任意笔记的未完成任务后加 `#今天`，会自动出现在这里。

```query
task-todo:#今天 -path:"9-首页/模板"
```

## 进行中任务

在任务后加 `#进行中`，会自动出现在这里。

```query
task-todo:#进行中 -path:"9-首页/模板"
```

## 今日新增 / 修改笔记

```base
filters:
  and:
    - 'file.ext == "md"'
    - 'file.path != this.file.path'
    - '!file.inFolder("9-首页/模板")'
    - or:
        - 'file.ctime.date().toString() == today().toString()'
        - 'file.mtime.date().toString() == today().toString()'
formulas:
  change_type: 'if(file.ctime.date().toString() == today().toString(), "新增", "修改")'
  changed_at: 'file.mtime.format("HH:mm")'
properties:
  file.name:
    displayName: 笔记
  formula.change_type:
    displayName: 类型
  formula.changed_at:
    displayName: 时间
views:
  - type: table
    name: 今日动态
    order:
      - file.name
      - formula.change_type
      - formula.changed_at
    sort:
      - property: file.mtime
        direction: DESC
    limit: 15
```

## 最近笔记

```base
filters:
  and:
    - 'file.ext == "md"'
    - 'file.path != this.file.path'
    - '!file.inFolder("9-首页/模板")'
    - 'file.mtime > now() - "7d"'
formulas:
  modified_at: 'file.mtime.format("MM-DD HH:mm")'
properties:
  file.name:
    displayName: 笔记
  formula.modified_at:
    displayName: 最近修改
views:
  - type: table
    name: 最近 7 天
    order:
      - file.name
      - formula.modified_at
    sort:
      - property: file.mtime
        direction: DESC
    limit: 10
```

